Three-Layer Security Architecture

Every login requires three independent verification steps before access is granted.

1. Credential Verification

Username and password verified against securely hashed records. Accounts lock after failed attempts.

2. Email OTP

A time-limited 6-digit OTP is sent to your registered corporate email. Valid for 4 minutes only.

3. Desktop Token

A Windows desktop application generates a single-use login token via the secure backend API.

Admin Provisioning

No public self-registration. All accounts are created and managed by authorized administrators only.

Full Audit Trail

Every login attempt, OTP event, and token generation is recorded with timestamps and IP addresses.
